# pg-undercover

《影武者詞殺》是 mobile-first 純 HTML/CSS/JS Playgrounds SAM。4–6 人本機與 AI 描述密詞後投票；多數同詞，唯一影武者持相近異詞。繁體中文詞庫位於 `words.json`。系列：**桌遊**。

```bash
npx --yes serve .
npx --yes vitest run
```
